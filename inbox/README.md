# inbox — 자동 갱신 입력 폴더

아임웹에서 내려받은 **주문 엑셀(`강의별_리스트*.xlsx`)** 을 여기에 넣어 두면,
매일 아침 자동 갱신이 새 파일을 감지해 15종 집계 + 오행 집계를 갱신합니다.

## 왜 Downloads가 아니라 여기인가
macOS는 `Downloads`·`Documents`·`Desktop`을 개인정보 보호(TCC)로 막아서
자동 실행 프로세스(launchd)가 읽지 못합니다. 이 폴더는 보호 대상이 아니라
별도 권한 설정 없이 동작합니다.

## 사용법
1. 아임웹 → 강의 → 강의별 집계 → '강의별 리스트' 엑셀 다운로드
2. 받은 파일을 이 폴더로 이동 (파일명은 그대로 두세요)
3. 다음 자동 갱신(매일 09:10)에 반영됩니다. 즉시 반영하려면:
   `python3 scripts/auto_refresh.py`

※ 이 폴더의 엑셀은 개인정보가 들어 있어 git에 올라가지 않습니다(.gitignore).
